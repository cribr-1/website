# Cribr | Property Intelligence & Transparency Platform

Cribr is a premium, AI-powered property research engine designed to provide unbiased, technical insights into real estate developments. Unlike traditional listing portals, Cribr prioritizes data transparency, builder verification, and analytical honesty over marketing hype.

## 🚀 Vision
To empower home buyers and researchers with the "truth behind the project" through advanced AI analysis, technical trade-off disclosures, and verified builder reputation metrics.

## 🛠 Tech Stack
- **Frontend**: Next.js 16.2 (App Router)
- **Styling**: Tailwind CSS + Framer Motion (Premium Minimalist Aesthetic)
- **Icons**: Lucide React
- **Backend**: Supabase (PostgreSQL)
- **Deployment**: Vercel

## 📁 Structure
- `/frontend`: The core Next.js application.
- `/schema_and_data.sql`: Database definitions for projects, builders, and localities.
- `/East_Bangalore_Projects_Dataset.csv`: Raw technical data used for intelligence profiling.

## 🌟 Key Features
- **Transparency Dashboard**: Data quality, RERA status, and commute scores.
- **Suitability Analysis**: AI-driven matching for families, investors, and first-time buyers.
- **Technical Trade-offs**: Honest disclosure of project risks and micro-market volatility.
- **Comparison Synthesis**: Side-by-side technical analysis of multiple developments.
- **Builder Trust Score**: Verified reputation metrics based on delivery history and quality.

## 🚦 Getting Started
1. Navigate to `frontend/`
2. Install dependencies: `npm install`
3. Run development server: `npm run dev`
4. Access at `http://localhost:3000`
